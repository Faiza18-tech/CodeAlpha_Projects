# MathFlow – Smart Calculator

MathFlow is a smart calculator web app built during my **CodeAlpha Internship** using HTML, CSS and vanilla JavaScript. It combines a clean landing page, standard and scientific calculators, unit converters and a saved history in one calm, easy-to-use interface.

## Features

- **Landing page** with a live calculator preview and a one-click start button
- **Standard calculator** for everyday math, with percentage, sign change and backspace
- **Scientific calculator** with sin, cos, tan, √, xʸ, log, ln, π, brackets and `Ans` (last answer)
- **Unit converters** for Energy, Area, Speed and Time
- **Calculation history** stored in the browser, with **Export to CSV** and **Clear history**
- **Settings** for dark/light theme, degree/radian mode and turning history on or off
- **Keyboard shortcuts**: type numbers and operators, press `Enter` to calculate and `Esc` to clear
- **Responsive layout** with a sidebar that turns into a menu on small screens

## How to Run

1. Download or clone the project and open the `MathFlow` folder in VS Code
2. Right-click `index.html` and choose **Open with Live Server**

You can also open `index.html` directly in any modern browser.
