# MathFlow Calculator — 3-file version

## Files
- `index.html` — page structure and content
- `style.css` — all design, responsive layout, animations and button effects
- `script.js` — calculator logic, history, converters, settings and navigation

## Run
Keep all three files in the same folder. Open `index.html` in your browser or use VS Code Live Server.

When editing:
- Change layout/text in `index.html`
- Change colors, spacing, responsiveness or animations in `style.css`
- Change calculations, history, converters or interactions in `script.js`
